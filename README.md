# Hukum-1-Termodinamika
Poster edukasi interaktif "Dinamika Transfer Energi" menjelaskan Hukum I Termodinamika (ΔU = Q − W) lewat empat kuadran proses: isotermal, isobarik, isokhorik, dan adiabatik. Tiap proses dilengkapi grafik P-V, rumus, dan simulasi gerak partikel real-time agar konsep energi yang abstrak mudah dipahami.
